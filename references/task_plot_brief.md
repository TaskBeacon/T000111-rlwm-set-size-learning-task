Title: RLWM Set-Size Learning Task
Construct: reinforcement learning / working memory

Purpose: show how set size changes only the number of stimulus-action mappings held within a block; every logical trial uses the same deterministic response-feedback sequence.

Rows/conditions:

- Set size 2 (low load): familiarization shows exactly 2 distinct colored geometric forms.
- Set size 4 (middle load): familiarization shows exactly 4 distinct colored geometric forms.
- Set size 6 (high load): familiarization shows exactly 6 distinct colored geometric forms.

Set sizes 3 and 5 use the identical timeline and are intentionally represented by the adjacent load examples. The figure should include a compact note: `Set sizes: 2, 3, 4, 5, 6`.

Participant-visible timeline per row:

1. `Familiarize` (self-paced): full set of 2/4/6 colored shapes on one centered row; no key mappings shown.
2. `Choose` (1.5 s max): one centered colored shape, with compact key labels `F  G  H` below the screen frame to indicate the allowed response.
3. `Feedback` (0.75 s): a split branch inside one snapshot, `CORRECT +1` in green or `INCORRECT 0` in red.
4. `ITI` (0.5 s): centered fixation cross `+`.

Accuracy constraints:

- The familiarization screen must contain exactly the row's stated number of shapes.
- One and only one shape appears during `Choose`.
- Feedback is deterministic binary +1/0; no probabilistic icons, coins, money, reward bars, or accumulated score.
- Do not show a cue, anticipation phase, multiple choice cards, or a second decision.
- Shape size must be consistent across rows and screens; set-size differences are count differences, not size differences.
- All screen boxes, labels, timing captions, and row separators must have ample spacing and no overlap.
