# CHANGELOG

All notable changes to `T000111-rlwm-set-size-learning-task` are documented here.

## [0.1.0] - 2026-08-29

### Added

- Implemented the deterministic RLWM stimulus-action learning protocol with set sizes 2-6.
- Added 18 independent blocks, 15 iterations per stimulus, three adjacent response keys, truthful binary feedback, and reproducible block mappings.
- Added protocol evidence, parameter/stimulus traceability, QA and simulation profiles, and TaskBeacon metadata.
- Added the publication task-flow figure and aligned browser companion task.

### Changed

- Adapted the reported 0.5-1 s feedback range to a fixed 0.75 s baseline duration.

### Fixed

- No fixes in the initial release.
